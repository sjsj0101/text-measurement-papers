# 来源与检索边界

[返回目录](../README.md) · [可复查的查询与筛选摘要](../data/search-log.json)

本版是截至 **2026-11-09** 的精选文献快照，收录51篇主目录和12篇补充。它以研究问题组织材料，不声称系统综述、全部相关文献或任何venue-year单元的完整覆盖。

## 种子与新增

初始60条引用全部完成本轮筛选：59篇进入目录，1篇一般信息系统实施中的用户抵抗研究因缺少直接文本测量关联而排除。预印本、正式发表版和改题版本合并为同一研究；旧引用中的标题、年份、作者与track由本轮来源核对修正。

另从EDITH命中中新增4篇：ITEM Ontology、RAD、PassivePy及叙事性文本测量研究。每篇的原始来源、中文说明、相关性和证据限制见主题详情。初始种子仅用于发现，不能作为发表身份证据。

180条返回记录的处置为：33条映射到27篇已收录研究，1条范围外，136条在题名和返回元数据初筛后未选入首版，10条保留为后续深查线索。后者含一个重复题名，共9个不同题名，尚未完成出版与内容核验。它们保留在检索摘要中，不计入63篇已收录论文，也不等于已经建立正式待核验条目。未选入不代表论文质量低或已逐篇读完。

## 网络核验与证据层次

网络核验围绕种子及EDITH候选的准确身份、正式版本、文章类型和内容展开。优先读取官方期刊、ACL Anthology、会议proceedings、官方接收名单及OpenReview记录；预印本用arXiv等原始入口。出版商限制访问时，逐条记录实际读取的是官方页索引内容、作者机构保存的正式排印稿、接受稿还是注册元数据。

每条论文保留`publication/content/metadata`用途的来源与真正核验日期。多数条目依据摘要，少量读取部分正文；没有把摘要核验写成阅读全文或实验复现。存在访问限制的条目保留限制说明，而不是声称所有外部链接已直接打开成功。

特别处理了以下容易混淆的情况：

- Prompt2Model标为System Demonstrations；Findings、Industry、Workshop各自标注。Workshop放在补充阅读。
- Active Synthetic Data Generation的官方COLM接收状态与arXiv版本关联，明确标为已接收；因任务与社会科学文本测量的距离列入补充。
- SetFit、GLiClass及缺乏官方会议证据的工作保留为预印本／工作论文，不依据作者自述升级发表身份。
- TrueTeacher使用正式发表题名，关联旧题名；首次在线年与卷期年不同的期刊论文在详情中说明。后续网站迁移日期不当作首次发表年。

## 跨仓库核对与已知缺口

本轮对四个已有仓库的372条记录进行了身份比对，包括主数据、LLM统计补充／待核验及量化金融期刊watchlist。识别到1篇相同研究：Prediction-powered inference；保留双向阅读所需的对方稳定ID与公开入口，详见[跨仓库关系](related-repositories.md)。未直接匹配不表示主题没有重叠。

后续优先事项是核验上述9个题名、扩展未返回的测量误差候选，以及根据实际选定的研究问题补足非英语文本、跨领域等值和独立真实标签评价。20个候选方向只是阅读与设计入口，其新颖性尚未做逐项充分检索论证。

私有库记录、完整摘要、全文、原始响应与本机路径不进入公开目录。本机维护日志由排除提交的HANDOFF记录位置。
